# Animasi Lottie di Halaman 404 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti ikon `Compass` di halaman 404 dengan animasi compass Lottie yang lebih besar dan hidup.

**Architecture:** Satu dependency baru (`@lottiefiles/dotlottie-web`, lightweight/framework-agnostic) me-render file DotLottie yang di-self-host di `/public/lottie/404-compass.lottie` lewat komponen client kecil `LottiePlayer.tsx`. Halaman `not-found.tsx` hanya menukar blok kotak ikon dengan komponen tersebut; elemen lain tidak berubah.

**Tech Stack:** Next.js 16.3 (App Router), React 19, `@lottiefiles/dotlottie-web` 0.79.0, Tailwind v4.

## Global Constraints

- File `.lottie` di-self-host di `/public/lottie/404-compass.lottie` (tidak load dari URL eksternal saat runtime).
- Satu-satunya perubahan `package.json` adalah menambah dependency `@lottiefiles/dotlottie-web` (versi `^0.79.0`); tidak ada dependency baru lain.
- Komponen LottiePlayer adalah client component (`"use client"`).
- Autoplay + loop true; tanpa prop tambahan yang tidak perlu (YAGNI).
- Gagal muat = animasi tidak muncul, tidak boleh crash.
- Verifikasi: `npx tsc --noEmit` exit 0, `npm run lint` exit 0, `npm run build` sukses.

- [ ] **Step 3: Tulis komponen LottiePlayer**

`src/components/LottiePlayer.tsx`:

```tsx
"use client";

import { useEffect, useRef } from "react";
import { DotLottie } from "@lottiefiles/dotlottie-web";

interface LottiePlayerProps {
  src: string;
  className?: string;
}

export default function LottiePlayer({ src, className }: LottiePlayerProps) {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    if (!canvasRef.current) return;
    const dotLottie = new DotLottie({
      canvas: canvasRef.current,
      src,
      autoplay: true,
      loop: true,
    });
    return () => {
      dotLottie.destroy();
    };
  }, [src]);

  return <canvas ref={canvasRef} className={className} />;
}
```
