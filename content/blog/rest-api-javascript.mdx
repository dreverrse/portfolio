REST API adalah jembatan antara aplikasi frontend dan data di server. Hampir semua aplikasi modern — mulai dari aplikasi mobile sampai website — berkomunikasi lewat API. Di artikel ini kita akan membuat REST API sederhana dengan tiga bahasa pemrograman yang populer.

## Apa itu REST API?

REST (Representational State Transfer) adalah gaya arsitektur yang memanfaatkan HTTP untuk mengirim data. Setiap operasi dipetakan ke method HTTP:

- `GET` untuk mengambil data
- `POST` untuk membuat data baru
- `PUT` untuk memperbarui data
- `DELETE` untuk menghapus data

## Membuat API dengan Node.js dan Express

Pertama, instal Express dan buat file `server.js`:

```javascript
const express = require("express");
const app = express();
const PORT = 3000;

app.use(express.json());

const todos = [
  { id: 1, title: "Belajar Express", done: false },
  { id: 2, title: "Membuat REST API", done: false },
];

app.get("/api/todos", (req, res) => {
  res.json(todos);
});

app.get("/api/todos/:id", (req, res) => {
  const todo = todos.find((t) => t.id === Number(req.params.id));
  if (!todo) return res.status(404).json({ error: "Todo tidak ditemukan" });
  res.json(todo);
});

app.post("/api/todos", (req, res) => {
  const todo = { id: todos.length + 1, title: req.body.title, done: false };
  todos.push(todo);
  res.status(201).json(todo);
});

app.listen(PORT, () => {
  console.log(`Server berjalan di http://localhost:${PORT}`);
});
```

Jalankan dengan perintah `node server.js`, lalu uji endpoint `GET http://localhost:3000/api/todos`.

## Versi Python dengan FastAPI

Jika kamu lebih nyaman dengan Python, FastAPI adalah pilihan yang sangat baik karena otomatis menghasilkan dokumentasi Swagger.

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class Todo(BaseModel):
    title: str

todos = [
    {"id": 1, "title": "Belajar FastAPI", "done": False},
    {"id": 2, "title": "Membuat REST API", "done": False},
]

@app.get("/api/todos")
def get_todos():
    return todos

@app.post("/api/todos")
def create_todo(todo: Todo):
    new_todo = {"id": len(todos) + 1, "title": todo.title, "done": False}
    todos.append(new_todo)
    return new_todo

@app.get("/api/todos/{todo_id}")
def get_todo(todo_id: int):
    todo = next((t for t in todos if t["id"] == todo_id), None)
    if not todo:
        raise HTTPException(status_code=404, detail="Todo tidak ditemukan")
    return todo
```

Instal dengan `pip install fastapi uvicorn` dan jalankan dengan `uvicorn main:app --reload`. Dokumentasi otomatis tersedia di `http://localhost:8000/docs`.

## Versi Go dengan net/http

Go terkenal dengan performa dan kesederhanaannya. Kita bisa membuat server HTTP tanpa library tambahan.

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"
)

type Todo struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
	Done  bool   `json:"done"`
}

var todos = []Todo{
	{ID: 1, Title: "Belajar Go", Done: false},
	{ID: 2, Title: "Membuat REST API", Done: false},
}

func getTodos(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(todos)
}

func main() {
	http.HandleFunc("/api/todos", getTodos)
	log.Println("Server berjalan di http://localhost:3000")
	log.Fatal(http.ListenAndServe(":3000", nil))
}
```

## Kesimpulan

Ketiga bahasa di atas sama-sama mampu membangun REST API yang solid. Pilihlah berdasarkan kebutuhan dan tim kamu:

- **Node.js** cocok untuk full-stack JavaScript
- **Python** unggul dalam prototipe cepat dan ekosistem data
- **Go** terbaik untuk performa tinggi dan deploy yang mudah

Semakin sering kamu latihan, semakin paham pola komunikasi API. Selamat mencoba!
